ffpa-attn wheel index

PEP 503 index of the FFPA CUDA-extension wheels. The extension is compiled for the CUDA 13 toolkit, so pick the CUDA your torch was built against (python -c "import torch; print(torch.version.cuda)"): 

pip install ffpa-attn --index-url https://vipshop.github.io/ffpa-attn/whl/cu13/ --extra-index-url https://pypi.org/simple

Install torch first. These wheels are built and tested against torch==2.11.0+cu130; nothing here carries torch of its own, so pip only resolves it when it is missing -- from PyPI, where it is not the cu130 build. Install it from the PyTorch index you normally use, then install this package.

The requirements come from PyPI, which is why the command carries --extra-index-url: this index holds ffpa-attn alone, with no dependencies and nothing else in it. Without a second index, pip would have to resolve every requirement against this one directory and fail on the first that is not already installed.

ffpa-attn is the same distribution PyPI lists, built here with the CUDA extension compiled in and tagged with the local version +cu13. That suffix is what keeps the two apart: it sorts above the plain release, so pip takes this build whenever both indexes are candidates, and a pure-Python wheel of the same release that is already installed no longer satisfies the requirement unchanged. Installing this replaces it -- one distribution, one ffpa_attn/ directory.

Platform tags: manylinux_2_38_x86_64 -- the tag reflects the GLIBC symbols the extension actually needs, so pip refuses a wheel this machine cannot run.
