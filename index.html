ffpa-attn-cu13 wheel index

PEP 503 index of the FFPA CUDA-extension wheels. The extension is compiled for the CUDA 13 toolkit, so pick the CUDA your torch was built against (python -c "import torch; print(torch.version.cuda)"): 

pip install ffpa-attn-cu13 --index-url https://vipshop.github.io/ffpa-attn/whl/cu13/

Install torch first. These wheels are built and tested against torch==2.11.0+cu130; nothing here carries torch of its own, so pip only resolves it when it is missing -- from PyPI, where it is not the cu130 build. Install it from the PyTorch index you normally use, then install this package.

--index-url on its own is complete for a machine that already has the runtime dependencies. Anything missing sends pip looking for it here, where only ffpa-attn-cu13 exists -- add --extra-index-url https://pypi.org/simple for those. That cannot shadow this package (ffpa-attn-cu13 is not on PyPI), but it can move your torch, which is the reason for the paragraph above.

Do not install PyPI's ffpa-attn next to this package: both own the ffpa_attn/ directory. This distribution installs the same Python package with the CUDA extension compiled in, so it replaces the pure-Python one.

Platform tags: manylinux_2_38_x86_64 -- the tag reflects the GLIBC symbols the extension actually needs, so pip refuses a wheel this machine cannot run.
